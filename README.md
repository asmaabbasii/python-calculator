# 🧮 Smart Calculator

A modern, responsive calculator web application built with **Python, Flask, HTML, CSS, and JavaScript**.

The project combines a clean user interface with practical calculator features such as calculation history, keyboard support, percentage calculations, and light/dark themes.

* ➕ Addition

* ➗ Division
* 🔢 Decimal calculations

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project

```bash
cd Python-Calculator
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

### 5. Open in your browser

```text
http://127.0.0.1:5000
```

## 🧠 How It Works

The application uses **Flask** to serve the web application and **JavaScript** to handle calculator interactions and calculations.

The interface is created with **HTML and CSS**, while JavaScript manages:

* User input
* Mathematical operations
* Calculation results
* Error handling
* Calculation history
* Theme preferences
* Keyboard interactions

Calculation history and theme preferences are stored locally in the browser using **LocalStorage**.
